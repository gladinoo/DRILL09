# Drill #9 - 소년 상하 좌우 이동 및 방향 바꾸기

한국공학대학교 2D 게임 프로그래밍 (2D Game Programming) Drill #9 과제

## 📋 과제 요구사항
1. **상하좌우 방향키 이동**: 상하좌우 방향키를 이용하여 소년을 상하좌우로 이동 (3점)
2. **IDLE 애니메이션**: 정지(IDLE) 상태에서는 제자리 대기 애니메이션 재생 (1점)
3. **방향 유지 및 이동 애니메이션**:
   - 좌/우 이동 시 해당 방향 이동 애니메이션 재생
   - 위/아래 이동 시 기존 바라보던 좌/우 방향 유지
4. **화면 경계면 제한**: 화면 경계에 다다르면 더 이상 밖으로 나가지 않음 (1점)
5. **리소스**:
   - 스프라이트 시트: `animation_sheet.png` (802 x 402)
   - 배경 이미지: `TUK_GROUND.png` (1280 x 1024)

## 🎮 조작법
- `Arrow Keys (상, 하, 좌, 우)`: 소년 이동
- `ESC`: 프로그램 종료
