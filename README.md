# Drill #9 - 소년 상하 좌우 이동 및 방향 바꾸기

한국공학대학교 2D 게임 프로그래밍 (2D Game Programming) Drill #9

---

## 📋 과제 요구사항 및 구현 내역

| 평가 항목 | 배점 | 구현 내용 | 상태 |
| :--- | :---: | :--- | :---: |
| **상하좌우 이동** | 3점 | 방향키(Arrow Keys) 입력에 따른 `dir_x`, `dir_y` 이동 처리 | ✅ 완료 |
| **IDLE 애니메이션** | 1점 | 이동 멈춤 시 (`dir_x == 0 and dir_y == 0`) 제자리 대기 애니메이션 재생 | ✅ 완료 |
| **화면 경계면 제한** | 1점 | `clamp`를 이용하여 캔버스(1280x1024) 밖으로 나가지 않도록 제한 | ✅ 완료 |
| **위/아래 이동 시 방향 유지** | - | `dir_x`가 0일 때 기존 `face_dir`을 유지하여 상하 이동 시에도 기존 좌/우 시선 유지 | ✅ 완료 |
